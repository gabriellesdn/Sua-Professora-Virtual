        Ativar a sua Professora Virtual

        Ela usa a IA gratuita do Google (Gemini). Você só precisa de uma conta Google e de uma chave gratuita. Leva cerca de 1 minuto:

        1. Abra a página das chaves.
          Abrir o Google AI Studio
        2. Entre com a sua conta Google e aceite os termos, se pedir.
        3. Clique em Criar chave de API (Create API key) e depois no ícone de copiar.
        4. Volte para esta aba e cole a chave aqui embaixo.

        Dúvidas comuns

        É grátis? O Gemini tem um plano gratuito, com limites de uso. Você não precisa ativar cobrança para usar a professora.

        Minha chave fica segura? Ela fica só neste navegador e vai direto para o Google. Trate como uma senha: não envie para ninguém.

        O Google pediu para importar um projeto? Se a sua conta já usa o Google Cloud, o AI Studio pede para importar um projeto antes de criar a chave. Escolha um e continue.

        O botão de criar chave está bloqueado? Contas de escola ou de trabalho podem não ter permissão. Tente com uma conta Google pessoal.

        E as minhas conversas? No plano gratuito, o Google pode usar o que você envia para melhorar os produtos dele. Evite informações sensíveis.
